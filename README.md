# IT Infrastructure Health Check and Incident Reporting Platform

## About
A web-based application developed to monitor IT infrastructure health and manage technical incidents. It helps users check system performance and report and track incidents easily.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- PSUtil

## Features
1. System Health Monitoring
2. Dashboard
3. Incident Reporting
4. Incident Severity (Low, Medium, High)
5. Incident Search and Filter
6. Resolve / Close Incidents

## How to Run
1. Install Python.
2. Install the required packages:
   `pip install -r requirements.txt`
3. Run the application:
   `python app.py`
